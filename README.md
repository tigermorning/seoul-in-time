# 서울 인 타임 (Seoul in Time)

지금 서 있는 그 자리에서, 그때를 본다.

서울 시내 특정 지점에 서서 휴대폰을 들면, 같은 위치·같은 방향에서 촬영된
수십 년 전 사진이 현재 풍경과 정렬되어 비교되는 위치 기반 아카이브 프로젝트.

레퍼런스: 홍콩 **City in Time** (홍콩 정부·홍콩대, 2021~).

## 원칙

  기반이다.
